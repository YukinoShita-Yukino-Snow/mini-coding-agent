# 代码导读

建议按 `cli.py -> agent.py -> model_client.py -> tools/` 的顺序阅读。

## 入口和配置

- `mini_agent/__main__.py`：支持 `python -m mini_agent`。
- `mini_agent/cli.py`：解析参数、组装组件、处理退出码并打印最终结果。
- `mini_agent/config.py`：从环境变量构建不可变 `Settings`，校验数值范围。

## 模型与循环

- `mini_agent/model_client.py`：调用 OpenAI 兼容 Chat Completions 接口，把 SDK 对象
  转换为项目自己的 `ModelReply` 和 `ToolCallRequest`，保存 Tool Call ID、JSON 参数
  以及供应商可能返回的 `reasoning_content`。
- `mini_agent/agent.py`：实现“请求模型 -> 执行工具 -> 回传结果 -> 继续决策”的主循环，
  统计步骤、工具成功次数和 Token，并处理多种终止条件。
- `mini_agent/context.py`：保存完整历史，为每次请求生成压缩副本，按完整工具轮次删除
  旧消息，避免破坏 Function Calling 的消息结构。

## 工具与安全

- `mini_agent/safety.py`：限制工作区路径，屏蔽凭据和内部目录，校验危险命令。
- `mini_agent/tools/definitions.py`：六个工具的 JSON Schema，是模型能够看到的工具接口。
- `mini_agent/tools/filesystem.py`：五个 UTF-8 文件工具，写入采用临时文件加原子替换。
- `mini_agent/tools/shell.py`：非 Shell 命令、stdin、超时、输出截断、本地程序路径解析
  和子进程凭据隔离。
- `mini_agent/tools/registry.py`：维护工具映射，解析 JSON 并统一返回
  `{ok, tool, data/error}`。

## 记录、测试和示例

- `mini_agent/events.py`：终端进度和 `.mini-agent/runs/*.jsonl` 本地记录。
- `tests/`：使用 Mock 模型验证核心逻辑，不产生 API 费用。
- `examples/todo_demo_template/`：可复现的 Todo CLI 基线。
- `scripts/create_demo_workspace.py`：只复制到不存在的新目录，避免覆盖旧结果。
