# 使用示例

以下示例工作区都应使用独立目录，不要把包含其他项目的上级目录交给 Agent。

## 扩展 Todo CLI

先生成公开示例的干净副本并确认基线测试：

```powershell
python -m scripts.create_demo_workspace D:\code\todo-agent-demo
python -m pytest -q D:\code\todo-agent-demo
```

然后运行：

```powershell
python -m mini_agent --workspace D:\code\todo-agent-demo --max-steps 20 "请为 Todo CLI 新增 stats 子命令，输出任务总数、已完成数、待办数和完成率；为空列表和非空列表增加测试；更新 README；运行完整测试并保持已有行为不变。"
```

这个任务会同时使用目录查看、文件读取、精确修改、测试执行和错误反馈等能力。

如果运行因最大步骤数或临时 API 问题停止，处理原因后可从该工作区的最新检查点继续：

```powershell
python -m mini_agent --workspace D:\code\todo-agent-demo --resume latest --max-steps 10
```

恢复会沿用原任务和历史消息，并要求模型先检查当前文件与测试状态。不要对已经显示
`completed` 的运行再次恢复。

## 创建并测试 C++ 程序

创建一个空工作区：

```powershell
New-Item -ItemType Directory -Force D:\code\fibonacci-demo
```

运行任务：

```powershell
python -m mini_agent --workspace D:\code\fibonacci-demo --max-steps 12 "请创建一个 C++17 斐波那契程序：读取非负整数 n 并输出 F(n)，处理负数和非法输入；使用 g++ 编译为 fib.exe；通过 stdin 测试 0、1、10 和负数，失败时自行修复。"
```

在 Windows 中，Agent 可以通过 `run_command` 的 `stdin` 参数给程序输入，并用
`./fib.exe` 运行工作区内生成的可执行文件。
